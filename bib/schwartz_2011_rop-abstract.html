Q: Exploit Hardening Made Easy

Download: Paper.

“Q: Exploit Hardening Made Easy” by Edward J. Schwartz, Thanassis Avgerinos, and David Brumley. In Proceedings of the USENIX Security Symposium, 2011.

Abstract

Prior work has shown that return oriented programming (ROP) can be used to bypass WaX, a software defense that stops shellcode, by reusing instructions from large libraries such as libc. Modern operating systems have since enabled address randomization (ASLR), which randomizes the location of libc, making these techniques unusable in practice. However, modern implementations leave smaller amounts of executable code unrandomized. Since ROP becomes more difficult as the amount of unrandomized code decreases, it has been unclear whether existing implementations are truly effective.

In this paper, we show existing defense implementations can be bypassed by developing new techniques for automatically creating ROP payloads from these small amounts of unrandomized code. Our techniques include semantic program verification for finding gadgets of various functionality, and a novel ROP compiler design that is resistant to missing gadget types. To demonstrate our techniques we build Q, an end-to-end system that automatically generates ROP payloads for a given binary. Q can produce payloads for 80% of Linux /usr/bin programs larger than 20K. We also show that Q can also automatically perform exploit hardening: given an exploit that cannot work with defenses turned on, Q outputs an exploit that bypasses both WaX and ASLR. We show that Q can harden nine real-world Linux and Windows exploits, allowing an attacker to automatically bypass currently implemented defenses.
